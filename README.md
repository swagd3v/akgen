# akgen

**[ak-studio/](ak-studio/)** is the app: a local browser studio that makes weapon skins from your images and first-person phone scenes, sharing one image collection. Start it with `ak-studio/Start AK Studio.cmd` or `npm start` inside that folder. See [ak-studio/README.md](ak-studio/README.md).

Also in this repository:

- `market-ritual/`: a separate chart project, unrelated to the studio.
- `iphone/`: the original hand and phone source downloads. The studio uses its own copies in `ak-studio/assets/phone/`.
